📊 Stock Analysis Dashboard

📌 Project Overview

This project is a professional Stock Analysis Dashboard developed using Excel to analyze stock market data, evaluate performance and risk, and visualize key investment insights through interactive tables, charts, pivot tables, and slicers.

The dashboard is designed to provide a structured and easy-to-understand view of stock performance and trading activity.

🎯 Project Objectives

- Analyze historical stock market data
- Track important stock performance metrics
- Compare monthly returns
- Analyze trading volume trends
- Evaluate stock risk indicators
- Identify price movement and performance trends
- Create an interactive and professional dashboard
- Practice real-world Excel data analysis and visualization

📂 Project Components

1. Main Data Table

Contains the structured stock market dataset used as the foundation for the entire analysis.

2. Key Metrics Table

Summarizes important stock performance indicators and provides a quick overview of the analyzed data.

3. Performance Analysis Table

Analyzes stock returns, price performance, and other key performance indicators.

4. Risk Analysis Table

Evaluates stock risk using relevant volatility and risk-related metrics.

5. Pivot Table

Provides summarized and categorized stock data for deeper analysis and reporting.

6. Interactive Slicers

Interactive filters are included for:

- Stock Name
- Sector
- Year
- Month

These slicers allow users to dynamically filter and explore the dashboard.

📈 Charts & Visualizations

Stock Price Trend

A line chart showing historical stock price movements and overall price trends.

Monthly Return Comparison

A comparison chart showing stock returns across different months to identify monthly performance patterns.

Volume Analysis

A chart visualizing trading volume trends and helping analyze changes in market activity.
